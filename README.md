# 🎮 파티 모집 디스코드 봇

게임 서버용 봇. 버튼만으로 게임 역할 받기 / 파티 모집 / 음성 이용시간 통계를 모두 사용할 수 있어요. 명령어를 외울 필요가 없어요.

## 기능

| 기능 | 설명 |
|------|------|
| 🎮 게임 역할 | 버튼으로 게임 역할을 받거나 뺌. 받으면 해당 게임 모집 알림이 옴 |
| ➕ 게임 추가/삭제 | 관리자가 버튼으로 게임 등록 → 역할 자동 생성 (코드 수정 불필요) |
| 📢 파티 모집 | 게임 선택 → 시간/인원/메모 입력 → 모집글 게시 + 역할 멘션 |
| ✋ 참가/취소 | 버튼으로 참가, 본인만 참가 취소 가능, 명단 실시간 갱신 |
| 🔒 마감 | 모집자/관리자가 마감 |
| 🔊 음성방 열기 | 모집글 버튼으로 음성방 자동 생성 (참가자만 입장 가능, 지정 카테고리 아래) |
| 📦 자동 종료 | 음성방 전원 퇴장 시 → 방 삭제 + 모집글을 아카이브 채널로 이동(재게시) + 스레드 삭제 |
| 🔊 음성 통계 | 음성채널 이용시간 자동 추적, 내 시간/주간 랭킹 조회 |
| 📋 활동 검토 | 매주 음성시간 검토 → 기준 미달 시 DM 경고(2회) → 3회째 강퇴 후보로 분류 |
| 🛡️ 안전장치 | 신규원(1주 미만)·면제역할 자동 제외, 강퇴는 관리자 버튼 승인 필수, 자동강퇴 모드 on/off |
| 📨 익명 건의함 | 버튼 → 모달로 익명 건의 → 관리자 채널에 게시. 작성자는 **서버 주인 1명만** 확인 가능 |
| 🕊️ 잠수 신고 | 본인이 직접 활동검토 면제 신청 (3일/1주/2주/1개월 또는 날짜 직접 입력). 관리자 승인식 |

## 1. 디스코드 봇 만들기

1. https://discord.com/developers/applications 접속 → **New Application**
2. 왼쪽 **Bot** 탭 → **Reset Token** → 토큰 복사 (이게 `DISCORD_TOKEN`)
3. 같은 화면에서 **Privileged Gateway Intents** 두 개 켜기:
   - ✅ **Server Members Intent**
   - ✅ **Presence Intent** 은 필요 없음, 끄세요
   - ✅ (Voice 추적은 기본 intent라 별도 설정 없음)
4. 왼쪽 **OAuth2 → URL Generator**:
   - Scopes: `bot`, `applications.commands`
   - Bot Permissions: `Manage Roles`, `Manage Channels`, `Move Members`, `Kick Members`, `Send Messages`, `Embed Links`, `Read Message History`, `Use Slash Commands`
   - 생성된 URL로 봇을 서버에 초대

> ⚠️ 봇 역할이 게임 역할보다 **위에** 있어야 역할을 부여할 수 있어요. 서버 설정 → 역할에서 봇 역할을 위로 올려주세요.
> ⚠️ `Manage Channels`(채널 관리)와 `Move Members`(멤버 이동) 권한이 있어야 음성방 자동 생성/삭제와 참가자 이동이 동작해요.
> ⚠️ `Kick Members`(멤버 추방) 권한은 활동검토의 강퇴 승인 기능에 필요해요. 강퇴 대상보다 봇 역할이 위에 있어야 해요.

## 2. 로컬에서 테스트

```bash
pip install -r requirements.txt

# 토큰을 환경변수로 설정
export DISCORD_TOKEN="여기에_봇_토큰"      # Windows: set DISCORD_TOKEN=...

python bot.py
```

봇이 켜지면 디스코드에서 패널을 설치할 채널로 가서:
```
/패널
```
입력하면 컨트롤 패널 + 관리자 패널이 설치돼요.

이후 흐름:
1. 관리자 패널에서 **➕ 게임 추가** → 게임 이름 + 이모지 입력
2. 관리자 패널에서 **📁 음성방 카테고리 지정** + **📦 아카이브 채널 지정** (음성방 기능 쓰려면 필수)
3. 유저들이 컨트롤 패널에서 **🎮 게임 역할 받기**
4. **📢 파티 모집하기** → 게임 선택 → 모집글 작성
5. 모집글에서 **🔊 음성방 열기** → 음성방 생성, 전원 나가면 자동 종료 + 아카이브

### 음성방 자동화 동작 방식
- `🔊 음성방 열기` 버튼 → 지정 카테고리 아래에 `🎮 게임명 파티` 음성방 생성 (참가자만 입장 가능)
- 봇이 음성 상태를 감시하다가 **봇 제외 전원이 나가면**:
  1. 음성방 삭제
  2. 모집글을 아카이브 채널에 재게시 (참가자 명단 그대로, "종료" 표시)
  3. 원본 모집글과 딸린 스레드 삭제
- 디스코드 API는 메시지 이동을 지원하지 않아서, "재게시 후 원본 삭제" 방식으로 이동 효과를 냅니다.

### 활동 검토 동작 방식
매주 멤버들의 음성 이용시간을 검토해 활동이 저조한 멤버를 정리하는 기능이에요. **여러 안전장치**가 들어가 있어요.

설정 (관리자 패널 → **📋 활동검토 설정**):
- **📑 로그 채널** — 검토 결과를 올릴 관리자 전용 채널 (필수, 미설정 시 검토 안 함)
- **🕐 기준 시간** — 주간 최소 음성시간 (기본 3시간)
- **🛡️ 면제 역할** — 이 역할 보유자는 검토에서 제외
- **🔁 자동강퇴 모드** — 기본 꺼짐(알림만). 켜면 강퇴 후보에 승인 버튼이 붙음

동작 흐름:
1. 매주 월요일 자동 실행 (또는 관리자 패널 **▶️ 지금 활동검토 실행**)
2. 자동 제외: 봇 / 면제 역할 보유자 / **가입 1주 미만 신규원**
3. 기준 미달자 → 경고 1회 누적 + DM 발송 (DM 차단 시 로그 채널에 기록)
4. 1·2회 미달 → 경고 DM / **연속 3회 미달** → 강퇴 후보로 분류
5. 강퇴 후보는 로그 채널에 리스트로 게시
   - 자동강퇴 모드가 **켜져 있어도** 봇은 절대 자동으로 내보내지 않아요
   - 관리자가 드롭다운에서 대상을 골라 **직접 승인**해야 실제 강퇴 실행
6. 강퇴는 kick 방식이라 **초대 링크로 재입장 가능** (밴 아님)
7. 기준 충족자는 경고 누적이 초기화됨

> 강퇴 전 대상에게도 "재입장 가능" 안내 DM이 발송돼요.

## 3. 데이터베이스 (Supabase)

이 봇은 **Supabase(PostgreSQL)** 에 데이터를 저장해요. Railway 재배포 시에도 데이터가 안전하게 보존돼요.

### 연결 문자열 얻기
1. Supabase 대시보드 → `party-bot` 프로젝트 → **Project Settings → Database**
2. **Connection string → Transaction pooler** 의 URI를 복사
   - 형식: `postgresql://postgres.PROJECT_REF:비밀번호@aws-0-ap-northeast-2.pooler.supabase.com:6543/postgres`
   - `[YOUR-PASSWORD]` 부분을 프로젝트 만들 때 정한 DB 비밀번호로 교체
   - 비밀번호를 잊었으면 같은 화면에서 **Reset database password** 로 재설정
3. 이 전체 문자열을 환경변수 `DATABASE_URL` 에 넣어요

> ⚠️ 봇은 풀러(pooler) 연결을 권장해요 — 포트 `6543` (Transaction mode). 동시 연결 수가 많은 봇에 적합해요.

테이블은 이미 생성돼 있어요. 추가 마이그레이션이 필요한 경우, `migrations/` 폴더의 SQL 파일을 Supabase 대시보드 → **SQL Editor** 에 붙여넣고 실행하세요.

## 4. 로컬 테스트

```bash
pip install -r requirements.txt

export DISCORD_TOKEN="봇_토큰"
export DATABASE_URL="postgresql://postgres.xxx:비밀번호@...pooler.supabase.com:6543/postgres"

python bot.py
```

봇이 켜지면 채널에서 `/패널 종류:유저용`, `/패널 종류:관리자용`, `/인증패널` 로 각 패널을 설치하세요.

## 5. Railway 배포 (24시간 구동, 무료)

1. 이 폴더를 GitHub 저장소로 push
2. https://railway.app → **New Project → Deploy from GitHub repo**
3. 저장소 선택
4. **Variables** 탭에서 `DISCORD_TOKEN` 과 `DATABASE_URL` 두 개 추가
5. 자동으로 `Procfile`의 `worker: python bot.py` 가 실행됨

> Railway 무료 티어는 매달 일정 크레딧을 줘요. 봇 하나는 충분히 돌아가요.
> 데이터는 Supabase에 있으니 **재배포해도 게임 목록·인증·경고·음성기록이 모두 보존돼요.** 마음껏 기능을 추가하고 다시 올리세요.

## 파일 구조

```
discord-party-bot/
├── bot.py                  # 메인 엔트리, Cog 로드, 영구 View 복원
├── database.py             # PostgreSQL(Supabase) 헬퍼 — asyncpg 풀
├── cogs/
│   ├── control_panel.py    # 컨트롤 패널 + 관리자 패널 (모든 기능 진입점)
│   ├── recruitment.py      # 파티 모집 (모달, 참가/취소/마감 버튼)
│   ├── game_roles.py       # 게임 추가/삭제, 역할 토글
│   └── voice_stats.py      # 음성 이용시간 추적 + 랭킹
├── requirements.txt
├── Procfile                # Railway 실행 설정
├── runtime.txt
└── .env.example
```

## 채널 권한 설정 (선택, 추천)

모집 채널을 봇 전용으로 만들려면 채널 설정 → 권한에서:
- `@everyone` → **메시지 보내기** ❌
- 봇 역할 → **메시지 보내기** ✅

이러면 채널에 봇이 만든 패널과 모집글만 깔끔하게 쌓여요.

## 주간 랭킹 자동 초기화 (선택)

현재는 관리자가 **🔄 주간 랭킹 초기화** 버튼으로 수동 초기화해요.
매주 자동 초기화를 원하면 `discord.ext.tasks` 로 스케줄러를 추가할 수 있어요. 말해주면 넣어줄게요.
